## SemaphoreCI docker-images

This repository's master branch tracks docker images pushed to the official [SemaphoreCI Docker Hub organisation](https://hub.docker.com/u/semaphoreci).

If you'd like a tool to be pre-installed, please send a request our way via email(support@semaphore.io) or by submitting a ticket through the support widget in your Semaphore dashboard.
